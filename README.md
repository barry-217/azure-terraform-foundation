# Azure Terraform Foundation

This repository is being rebuilt hands-on as part of an Azure and Terraform learning project.

The implementation will be recreated step by step using Terraform, Microsoft Azure, Git, and GitHub.

## Planned Components

- Resource Group and standardized tags
- Virtual Network and Network Security Group
- Storage Account
- Azure Key Vault
- Log Analytics Workspace
- Terraform variables, outputs, and documentation

> Status: Hands-on rebuild in progress.
